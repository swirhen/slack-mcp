slack-mcp 管理

ログイン

AI ごとにコネクタの URL を発行します。URL をその AI (claude.ai のカスタムコネクタなど) に登録すると、投稿はここで決めた名前の bot として行われます。

Slack のワークスペースごとのトークンです。保存すると accounts/<名前>.toml を書きます。トークンは画面に表示しません。

Slack アプリの作り方

  1. そのワークスペースに入っているアカウントで api.slack.com/apps を開きます。
  2. Create New App → From a manifest でワークスペースを選び、下のマニフェストを貼って作ります。すでにアプリがあるときは、アプリの App Manifest に貼り直して保存します。
  3. Install App から Install (または Reinstall) to Workspace で許可します。
  4. 表示される User OAuth Token (xoxp-) と Bot User OAuth Token (xoxb-) を、「Slack アカウント」タブで登録します。
  5. bot をプライベートチャンネルに投稿させたいときは、そのチャンネルで /invite @アプリ名 をします。公開チャンネルには招待なしで投稿できます。
